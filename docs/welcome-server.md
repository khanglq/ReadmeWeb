# Chào mừng đến với ReadmeWeb trên Server

Tài liệu này được lưu trực tiếp trên máy chủ web của bạn!

---

## 🚀 Tính năng Server Documents

- **Tự động lưu & đọc trực tiếp**: Khi bạn chỉnh sửa tài liệu này và nhấn **Save** (`Ctrl + S`), dữ liệu sẽ được gửi qua API và lưu ngay lập tức vào ổ cứng máy chủ.
- **Quét thư mục đệ quy**: Toàn bộ file `.md` và `.markdown` trong thư mục cấu hình sẽ được tự động nhận diện và hiển thị trong danh sách.
- **Hỗ trợ đầy đủ định dạng**:
  - Công thức Toán KaTeX: $E = mc^2$ hoặc $$\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$$
  - Sơ đồ tương tác Mermaid
  - Tô màu cú pháp Code (Highlight.js)
  - Bảng biểu, Task lists, v.v.

---

> [!TIP]
> Bạn có thể mở tài liệu này và sửa đổi trực tiếp từ giao diện web bằng cách:
> 1. Bấm nút **Server Documents** trên thanh công cụ TopBar.
> 2. Chọn thư mục **All docs of server** -> chọn **welcome-server.md**.
> 3. Chỉnh sửa và bấm **Save**!
